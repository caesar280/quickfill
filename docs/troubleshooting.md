# 常见问题与排查

都是实战里踩过的坑（2026 秋招季多个真实 ATS 系统验证过）。

## 填充类

**Q：点了「一键填充」没反应？**
1. 看面板「本站点启用」是否勾上（按域名记忆，一次开启长期生效）
2. 部分站点把表单放在 iframe 里——脚本按设计不跨 iframe，需在 iframe 页面刷新后单独填
3. Tampermonkey 装了 ≠ 生效：确认该站点脚本已启用、浏览器没开多个扩展冲突

**Q：匹配预览是绿的，实际填不进去？**
多半是级联控件把整个队列拖死了。v3.1.0 起级联有 6 秒总预算、超时快速放弃标橙，后续字段不再被拖累。若仍卡：把该字段在 profile 里补 `_三级` 变体值（如 `浙江省-杭州市-西湖区`），级联路径越标准越好点。

**Q：单选组（性别/政治面貌）填不上？**
老版本会把选项 label（如「共青团员」）误当组名导致匹配失败。v3.1.0 修复：取 label 时跳过含 radio/checkbox 的，组名匹配失败时按 radio `name` 兜底（gender/sex→性别、political→政治面貌、marital→婚姻）。自建页面若用自定义单选，`name` 属性按这些标准词命名可提高命中率。

**Q：级联省市区填了一半就停？**
级联判定要求值能按 `-` 分层。检查 profile：`籍贯_三级` 用全称+短横线（`浙江省-杭州市-西湖区`），别用空格或「/」分隔；菜单文字与值保持一致（全称对全称）。

**Q：「未找到」的字段很多？**
「未找到」≠ 失败：profile 有 60+ 键，页面只有十几个控件，未找到的大多是页面没有的字段。只看绿/橙描边即可。

## 构建 / 安装类

**Q：`build_v3.py` 报「模板里找不到 __PROFILE_JSON__ 占位符」？**
模板被改动过。恢复 `__PROFILE_JSON__` 占位符（在 DEFAULT_PROFILE 附近），或重新拉取本仓库的模板。

**Q：生成的 user.js 装上后 Tampermonkey 报语法错误？**
构建后必须过 `node --check`；CI 也跑了这一步。若仍报错，多半是 profile.json 里有裸换行/未转义引号——用标准 JSON 校验器先过一遍再 build。

**Q：改了资料没生效？**
改 `profile.json` → 重跑 `python build_v3.py` → **Tampermonkey 里覆盖安装新产物**（旧脚本不会自动更新）。临时改可直接用面板「编辑资料」粘贴新 JSON。

## 隐私 / 安全类

**Q：我的资料会上传吗？**
不会。资料只存在两处：`profile.json`（本地文件，已 gitignore）和 Tampermonkey 扩展域存储（`GM_setValue`，页面脚本读不到）。没有任何网络上报。

**Q：为什么不自动填证件号/密码/验证码？**
设计红线（见 `manual_fields`）：本脚本只解决「重复抄写」这一件事，敏感字段与一切不可逆操作（提交）永远人工。别问怎么关掉这个限制——那是特性不是 bug。
